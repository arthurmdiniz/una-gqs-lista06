# TempoDeslocamento.java

Programa em Java que calcula o tempo de deslocamento a partir da distância e da velocidade média.

## Como funciona

1. O usuário informa a distância em quilômetros (km).
2. O usuário informa a velocidade média em km/h.
3. O programa calcula o tempo por meio da fórmula:

```
tempo = distancia / velocidade
```

4. O resultado é exibido em horas.

## Exemplo de execução

```
Digite a distância em km: 120
Digite a velocidade média em km/h: 60
Tempo de deslocamento: 2.0 horas
```

## Compilação e execução

```
javac TempoDeslocamento.java
java TempoDeslocamento
```
